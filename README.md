# 📦 Roblox Modular Framework (UI Loader & Unit Spawner)

ชุดโค้ดพื้นฐานสำหรับนักพัฒนาเกม Roblox ประกอบด้วย 2 ระบบหลัก:
1. **Universal UI Loader (Client):** โหลดโค้ด UI จาก GitHub แบบ Real-time (ไม่ต้อง Publish เกมใหม่ทุกครั้งที่แก้ UI)
2. **Unit Spawner Service (Server):** ระบบเสกโมเดล/ยูนิตลงในเกมอย่างปลอดภัย ผ่านการตรวจสอบจากฝั่งเซิร์ฟเวอร์

> ⚠️ **คำเตือนสำคัญ (Disclaimer):** 
> โค้ดชุดนี้จัดทำขึ้นเพื่อการศึกษา และใช้สำหรับ **การพัฒนาเกมของคุณเอง** บน Roblox Studio เท่านั้น 
> **ห้ามนำไปใช้** ผ่านโปรแกรม Executor เพื่อเจาะระบบ (Exploit) หรือโกงเกมของผู้อื่นเด็ดขาด เนื่องจากการกระทำดังกล่าวจะส่งผลให้บัญชีถูกแบน (Ban) ตามข้อกำหนดของ Roblox (TOS) และอาจเป็นอันตรายต่อเครื่องคอมพิวเตอร์ของคุณ
